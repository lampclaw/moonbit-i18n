## Scope and compatibility

This maintenance release upgrades the supported MoonBit archive to
`0.10.20+65efd5b93`, Moon `0.1.20261104`, and bundled publishing client
`0.1.20261030`. Development tooling is pinned to Node LTS `26.13.1`, npm
`12.2.2`, Playwright `1.65.1`, and `messageformat@4.1.0`.

Library dependencies are XML `0.6.1`, x `0.5.7`, parser `0.4.8`, async
`0.22.9`, and normalization `0.5.2`. The maintained example uses Rabbita
`0.17.0` and Warren `0.4.5` with its bundled minifier. Normalization retains
Unicode 16.0.0 tables. CI pins setup-node `v7.1.0` and checkout `v7.0.1` by
full commit SHA and verifies the MoonBit installer checksums.

Source and generated code use prefix `#derive(...)`; public interface output
uses the compiler's `Int32` alias spelling. The current interface and generator
hashes are recorded in
[`current-toolchain.json`](../contracts/current-toolchain.json). The original
[`1.0-candidate.json`](../contracts/1.0-candidate.json), previous
[`0.9.3-toolchain.json`](../contracts/0.9.3-toolchain.json), and normative
[`standards.json`](../../tests/unicode-mf2/standards.json) are unchanged.
CI checks the original frozen API after normalizing only the reviewed compiler
representation changes and previously reviewed explicit derived methods.

The Node Intl host is recorded separately: ICU `78.3`, CLDR `48.0`, Unicode
`17.0`, and time-zone data `2026e`. Normative MF2/CLDR/IANA inputs and supported
profiles remain frozen. The independent oracle now uses stable currency and
percent functions from `messageformat@4.1.0`; only experimental date/time cases
load its draft functions.

The removed binary-install commands are replaced by `moon install ... --bin`.
This installer produces native `i18n`/`i18n.exe`; documentation and consumer
checks explicitly rename it to `moon-i18n`/`moon-i18n.exe`. Portable execution
continues through the exact-version `moonx` command.
