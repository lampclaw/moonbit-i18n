This release completes the `0.4.x` production Web-delivery roadmap gate.
Canonical authoring remains one JSON resource per locale. Schema namespaces
are emitted as independently deployable catalog-v2 chunks with deterministic
paths, byte counts and SHA-256 identities. Generated APIs expose typed
namespace metadata and readiness, while the runtime validates and atomically
merges chunks without owning networking, caching, persistence, or application
locale state.

The maintained Rabbita example embeds English, concurrently loads the required
Chinese `common` and `todo_ui` namespaces, verifies exact response bytes before
installation, retries only missing chunks, preserves the previous locale on
failure, and exercises fallback through an intentionally unloaded namespace.
Its release JavaScript measured 205346 raw bytes and 48278 gzip bytes, with
2060 embedded-catalog bytes, a 1100-byte largest dynamic chunk, and a 2123-byte
deployment manifest, all inside published budgets.

This release retains profile
`lampclaw-mf2-strict-v1+lampclaw-datetime-v1`; it does not claim complete
Unicode MessageFormat 2 conformance. The next roadmap phase introduces a new
profile for the pinned stable MF2 syntax and interchange data model instead of
silently changing strict-v1 semantics.
