## Scope and compatibility

This maintenance release upgrades the supported MoonBit baseline to
`0.10.15+943464bfa`, Moon `0.1.20261012`, with bundled publishing client
`0.1.20260911`. Node remains `26.7.0`, Playwright remains `1.62.1`, and the MF2,
Unicode data, and Intl host contracts remain frozen.

Library dependency changes are parser `0.4.4`, async `0.22.4`, and
`moonbit-community/normalization@0.5.2`; normalization tables retain Unicode
16.0.0 data. The example uses Rabbita `0.16.5` and Warren `0.4.5` with its bundled
minifier. Compiler compatibility changes preserve previously implicit derived
Eq/Debug methods explicitly. The original candidate snapshot remains unchanged;
the separately reviewed compiler representation and its checks are recorded in
[`0.9.3-toolchain.json`](../contracts/0.9.3-toolchain.json).

The application-owned catalog loader now bounds headers and body by a
10-second deadline, counts actual streamed bytes against the generated exact
length and 64 KiB ceiling, decodes strict UTF-8, and retains SHA-256 verification
before installation. Failures preserve the current locale and allow retry of
missing chunks; attempt IDs reject stale callbacks. The loader remains outside
the published library archive.
