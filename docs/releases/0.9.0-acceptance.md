## MF2 and contract scope accepted

The stable authoring profile is now `unicode-mf2-ldml48.2-js-v2`. The 0.8
`unicode-mf2-ldml48.2-js-v1` profile remains a warning-emitting migration
profile, while Draft date/time behavior is available only through explicit
`unicode-mf2-ldml48.2-js-v2+experimental-datetime-v1` opt-in.

Conformance is pinned to the Unicode MessageFormat Working Group LDML 48.2 tag
at commit `7f142fb4f1f5ea6ab1eb34ce2b87e918ca9fd331`. The one-to-one
normative matrix contains 77 anchored rows: 73 pass and four Draft-function
rows are correctly N/A for the stable
profile, with zero blockers. All six stable functions and 40 stable options
are covered. The independent differential set contains 24 cases, split into
20 stable and four experimental cases, with zero unexplained failures. The
real-browser harness executes 270 syntax/data-model, 67 resolution, 104 stable
function, 20 experimental function, and 24 differential cases in each browser
engine.

`docs/contracts/1.0-candidate.json` freezes the public interface hashes,
generator template, profile and wire contracts, CLI surface, diagnostics, and
support policy. CI checks this snapshot so post-0.9 development cannot
silently change the 1.0 candidate contract.
