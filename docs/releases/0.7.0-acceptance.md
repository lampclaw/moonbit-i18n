This release completes the `0.7.x` default-function and registry roadmap gate.

`unicode-mf2-ldml48.2-default-functions-v1` implements the pinned stable
required `:string`, `:number`, `:integer`, `:offset`, `:currency`, and

path; structured output requests `formatToParts()` only when fields are
needed.

commit `d115a614079678850aac8b52742360e888b8f027`. In addition to the 270
syntax/data-model and 67 resolution cases, all 124 pinned function cases pass

profile. Explicit `messageProfile`, private-datetime migration, the normative
