## MF2 scope accepted

This release adds explicit `messageProfile` authoring and ships the aggregate
JavaScript standards profile `unicode-mf2-ldml48.2-js-v1`, while preserving
the documented compatibility profile and migration diagnostics. Conformance
remains pinned to Unicode MessageFormat 2 LDML 48.2 upstream commit
`d115a614079678850aac8b52742360e888b8f027`.

The machine-readable requirement matrix covers 20 scoped normative rows, all
six stable default functions, and all 40 stable options. The independent Node
26 differential suite contains 24 cases: 15 exact matches, two error-semantic
matches, seven exact host-CLDR results, and zero unexplained semantic
differences. The pinned syntax/data-model, resolution, and default-function
suites contain 270, 67, and 124 cases. Draft LDML behavior remains explicitly
outside the stable conformance claim.

This release completes the `0.8.x` explicit-profile, migration, and
conformance-evidence roadmap gate.
